# 住

台北两段加台南一段。入台证没下来前只订可免费取消。

- 姓名拼音必须和护照、机票、入台证同一套。Agoda 或 Booking 都行，台湾 Agoda 往往更便宜；人在荷兰，Booking 出问题找客服方便。Trip.com、酒店官网也可以。别订不接待陆客、或不写护照的民宿。证和机票锁死后再改不可退。
- 位置比星级重要：捷运步行 5 分钟内，要 24 小时柜台。第一天清晨到，没有夜班会在门口等。
- 台北两段尽量同一家（中山或台北车站）。西门吵。不要订士林、北投。
- 台南住中西区国华街圈，不要住高铁站，也不要住永康区。
- 房间：没暖气也行，无窗好睡。带欧转美接头。不要为浴缸升级。
