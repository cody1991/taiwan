# 行

岛上不租车。机票见 [航班](flights.md)。

- 悠游卡：机场捷运站或超商买。多次证出岛可以不退，下次还能用。
- 钱：荷兰换台币汇率差，只换 2000–4000 够第一天。其余 7-11 ATM。Visa / Mastercard 比 Maestro 稳。取款选台币，拒绝动态货币转换。1000 元大钞小摊常不收，便利店先拆。夜市现金。不用给小费。出发前跟银行报台湾和大陆。
- 电话：台湾 eSIM，桃园也能买实体卡。双卡留国内号，到深圳再开。台湾用 Google 地图，菜单用翻译拍照，离线下载繁中。到深圳改高德，开微信乘车码。
- 机场捷运进出桃园。直达车比较快。华航多半第二航厦（A13），南航多半第一航厦（A12），以登机牌为准。12/24 市区 9:30 前出发。
- 高铁只订两张对号座：12/20 台北→台南，12/22 早班回。护照号订，大约出发前 28 天放票。早鸟能抢就抢。车站或 ibon 取。台北车站高铁和机场捷运不在同一大厅，预留 40 分钟。不要赌自由座。
- 九份：周六尽量上午从忠孝复兴坐 1062。16:00 前坐回程。不加金瓜石。雨改北投或淡水。
- 台南靠走和计程车。捷运末班大约午夜。街上几乎没垃圾桶。报警 110，救护 119。
- LINE：出发前装。台南 Line Taxi / Uber。酒店客服常只回 LINE。
- YouBike：悠游卡借，市区短骑，别骑去九份。
- 便利店：关东煮、厕所、ATM。ibon 能取高铁票。雨伞落地买。
