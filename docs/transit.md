# 行

岛上不租车。机票见 [航班](flights.md)。

- 悠游卡：机场捷运站或超商买。多次证出岛可以不退，下次还能用。
- 钱：带 2000–4000 新台币够第一天。后面优先 7-11 ATM。Visa / Mastercard 比 Maestro 稳。微信支付宝不要当主力。夜市现金。不用给小费。出发前跟银行报台湾和大陆。
- 电话：出发前台湾 eSIM，或桃园买卡。台湾用 Google 地图。到深圳改高德，切回国内号。
- 机场捷运进出桃园。12/24 市区 10 点前出发。宝安地铁 11 号或计程车回南山。
- 高铁只订两张对号座：12/20 台北→台南，12/22 早班回。护照号订，大约出发前 28 天放票。车站用护照取。不要赌自由座。
- 九份：忠孝复兴转 1062，约 1 小时。16:00 前坐回程。雨改北投。
- 台南靠走和计程车。街上几乎没垃圾桶，包装捏在包里。
