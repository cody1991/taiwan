# 航班

三段分开买，不要强行一张票串荷兰–台湾–深圳。两岸票和欧洲票规则、行李、改签都不一样。

## 1. 阿姆斯特丹 → 桃园（12/25）

直飞有两家，优先华航早班。

| 航班 | 典型时刻 | 机型 | 适合谁 |
| --- | --- | --- | --- |
| 华航 CI74 | 周五约 10:40 AMS → 次日 06:35 TPE | A350 | **首选**。12/25 圣诞公假走 |
| 荷航 KL807 | 晚上约 20:05 AMS → 次日下午 TPE | 789/772 | 当天还要上班才考虑。下午到，第一天废掉 |

CI74 目前是周一、三、五、六。**2026-12-25 是周五**，对得上。去程圣诞高峰，10 月就开始看，能免费改期就买。

中转备选（直飞卖光或贵到离谱时）：多哈 QR、伊斯坦布尔 TK、法兰克福 LH、首尔 KE。去程不建议为了玩而中转——你要赶台湾天数和跨年。

## 2. 桃园 → 深圳宝安（01/02）

每天有直飞，大约 1 小时 50 分。

常见航班号：CI527、ZH9072/9074、CZ3088、B7187。出发多在 12:30–17:35，正好台湾行程收尾。

备选：

- 桃园 → 香港 → 深圳湾/福田口岸：如果直飞订不到，香港落地去南山其实很顺。
- 高雄 → 深圳：只有你改成「南部结束、不去台北跨年」才值得。本方案要跨年，还是桃园出。

两岸票用航司 App 或携程/飞猪即可，持中国护照 + 台湾入台证出境。

## 3. 深圳/广州 → 阿姆斯特丹（春节后）

**深圳宝安没有直飞阿姆斯特丹。** 南航以前有，现在没有了。

### 推荐：广州白云直飞

南航 **CZ307 CAN → AMS**，冬春时刻从 2026-10-25 起大致是：

- 周一、二、四、五、日 13:00 → 18:35
- **周六、周三冬春没有这班**

所以不要订 2/13（周六）。订 **2/14（周日）** 或 **2/12（周五）**。

南山出发：深圳北 / 福田 → 广州南，再机场大巴或地铁去白云。预留 4 小时以上门到门。2/14 周日高铁仍密。

### 也很稳：香港出发

深圳湾口岸 → 香港机场，国泰或荷航 HKG–AMS 直飞，产品往往比南航舒服。春节口岸会排队，当天请留 5–6 小时。

### 锦上添花：中转玩 2 晚

回程才适合停，去程不要停。

| 方案 | 怎么走 | 停多久 | 值不值得 |
| --- | --- | --- | --- |
| **伊斯坦布尔** | 深航/南航/TK：SZX 或 CAN → IST → AMS | 2 晚 | **最值得**。城好走，冬天气温接近荷兰，倒时差顺 |
| 多哈 | 卡航 QR：CAN/HKG → DOH → AMS | 1 晚或长过境 | 机场本身是景点；市区要签证/过境签，麻烦一点 |
| 首尔 / 东京 | 经 ICN/NRT | 2 晚 | 又一次东亚，和台湾有点重复 |
| 新加坡 | SQ | 1–2 晚 | 顺，但 2 月新加坡偏热，和刚离开的深圳反差小 |

伊斯坦布尔建议：2/13 或 2/14 从深圳/广州飞 IST，玩 2/15–2/16，2/17 到 AMS。荷兰那边 2/18 周四上班，再请 2 天。TK 的 Stopover 产品经常含酒店折扣。

## 订票顺序

1. **现在–10 月**：先盯 2 月回程 CAN/HKG/IST → AMS。春节中欧是卖方市场。
2. **10 月**：买 12/25 AMS–TPE，选可改期。
3. **11 月**：买 1/2 TPE–SZX，便宜且机位多。
4. 三段都买单程。不要荷兰往返，中间那段用不上回程券。
