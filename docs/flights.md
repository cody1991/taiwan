# 航班

两段分开买。时刻按 2026-10-25 起的冬春班表，买之前在航司网站再对一次。

## 1. 阿姆斯特丹 → 桃园（12/16 周三）

**首选：华航 CI74**，约 11:00 AMS → 次日约 06:15 TPE，A350。这天周一、三、五、六有班，周三对得上。夏冬时刻可能差十几分钟。

**不要指望荷航 KL807。** 冬春这班多在周二、四、五、日晚上约 20:05，12/16 周三通常没有。华航没位再改 12/14 周一 CI74，或首尔 KE / 法兰克福 LH 中转，去程不要停下来玩。

## 2. 桃园 → 深圳宝安（12/24 周四）

从台北出，预留 3 小时。约 1 小时 50 分。

| 航班 | 时刻（冬春） | 12/24 | 说明 |
| --- | --- | --- | --- |
| **南航 CZ3088** | 约 13:40 → 15:50 | 有 | **首选**，下午到南山过平安夜 |
| 华航 CI527 | 约 15:30 → 17:25 | 有 | 和去程同一家 |
| 立荣 B7187 | 约 16:25 → 18:25 | 有 | 备选 |
| 深航 ZH9074 | 约 17:35 → 19:35 | 每天 | 再晚到家就挤 |
| 深航 ZH9072 | 约 12:30 | 冬春多半周日 | **别盯这班** |

订不到直飞：桃园 → 香港 → 深圳湾。

## 订票顺序

1. **10 月**：买 12/16 AMS–TPE，选可改期。
2. **11 月**：买 12/24 TPE–SZX，优先 CZ3088。
3. 两段都买单程。
