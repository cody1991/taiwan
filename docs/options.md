# 三种走法

推荐方案 A。B 适合深圳也不能远程。C 是回程想玩一站。

## A. 推荐：台湾 8 天 7 晚 + 南山待到过完年

| | |
| --- | --- |
| 去程 | 12/25 AMS → TPE（圣诞公假） |
| 台湾 | 12/26–01/02，台北 + 台南 + 跨年 |
| 深圳 | 01/02–02/14 |
| 回程 | 02/14 CAN → AMS 直飞 |
| 荷兰年假 | 大约 4 个工作日（12/28–31） |

## B. 更短：只待台北

不去台南。1 月中从广州或香港回荷兰。只有深圳也不能远程时才用。

## C. 锦上添花：A + 伊斯坦布尔 2 晚

行程同 A，只改回程：2/13 或 2/14 飞 IST，2/17 到 AMS。
